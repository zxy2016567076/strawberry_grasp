# 当前实现与运行入口

## 六轴软件链路

入口 `python -m software_v3.demo`。六个转动关节与夹爪独立建模，配置轴向、连杆、零位和限位；提供全位姿 FK/IK、基座坐标转换、多阶段抓放、关节步进、双速和八状态调度。目标、几何、标定与压力样例均标注为合成软件输入。

V3 通过版本/轴数/夹爪能力握手连接模拟 MCU，包含 CRC、序号和接收端检查；错误退出停带、冻结并锁存故障。它不直接打开真实串口。

## 板端与视觉代码

`vision/pi/main.py` 提供树莓派视觉分拣入口；`mcu/hal_entry.c` 提供 RA6M5 定姿态分拣、压力阈值夹持与 float MLP 诊断代码。该板端控制接口是五个运动关节加夹爪，不能接收六运动轴模拟协议。

`pickup_v2/pi/main_pickup.py` 提供视觉定位和固定工具俯仰 IK 的另一运行入口；`pickup_v2/pi/tests` 验证相应坐标、运动学和协议模块。K 指令的六通道包含夹爪，与 V3 `joints_deg` 的六个运动关节不同。

## 接口与验证

六轴模拟需要专用的六运动轴加夹爪接收端；不能将 V3 输出直接发送给上述板端。硬件接入前需机构/标定/固件匹配与真实状态同步。

YOLO 指标可追溯至训练日志；MLP 权重与预处理入口见 [TINYML.md](TINYML.md)。软件调度时钟不用于证明板端采样率或推理时延。
