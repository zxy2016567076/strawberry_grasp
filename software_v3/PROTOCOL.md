# V3 模拟 UART 协议

板端 K 六通道顺序是底座、肩、肘、腕俯仰、腕旋转、夹爪；V3 的 `joints_deg` 是六个真正运动关节，夹爪走独立 `grip`。不兼容板端 A/B/C/G/X 或 pickup_v2 协议。

当前仅内存传递字节，不创建串口连接。未来需要专用六轴 MCU 固件，不能把模拟接收器直接替换为旧串口设备。

## 帧格式

`~` + **小写十六进制 UTF-8 JSON** + `:` + CRC32（原始 JSON 字节，8 位小写十六进制）+ LF。全帧上限 2048 字节。CRC 检测传输错误，不做身份认证。

外层字符仅 `~0123456789abcdef:\n`，不含板端大写动作字母；避免新前缀后仍带 A/B/C 等字母导致板端逐字节解析器触发动作。已检查本仓库板端大小写匹配逻辑，对未知固件不作安全兼容保证。

公共字段：`v:3`、`model:"six-motion-plus-gripper"`、严格递增整数 `seq`、`op`。首次 hello，ACK 必须确认 `motion_axes:6,gripper_axes:1`；其他固件 DONE/OK 不能完成握手。

| op | 额外字段 | 行为 |
|---|---|---|
| hello | 无 | 版本/模型/能力握手 |
| step | joints_deg：6 有限角；speed：fast/slow | 单步执行，接收端复核限位、增量、最小时间间隔和 TCP 工作空间 |
| grip | action：open/close | 独立夹爪；close 启动非阻塞压力任务 |
| belt | enabled：布尔 | 模拟传送带 |
| ping | 无 | 保活 |
| stop | 无 | 故障锁存、冻结命令、停带 |
| ack | status：ok；motion_axes：6；gripper_axes：1 | 回显 seq，确认命令接受 |

ACK 不是编码器反馈到位。模型标识确认轴语义，不校验机器标定哈希；真实连接还需设备身份、标定一致性与启动关节状态同步。

错误帧、CRC、错误版本、重放、越限和超步幅锁存故障，Python 接收器抛 `Halt`，不返回成功 ACK。`FrameStream` 独立提供 UART 分片/多帧拆包，超限清空报错；模拟执行以整帧交付。

1 s 无有效通信触发看门狗；普通等待每 200 ms ping，丢 ACK 故障停止保活以验证 MCU 独立冻结。错误后不自动重连或重试。物理 UART、电气波形、吞吐、编码器与制动均未验证。
